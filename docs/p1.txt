class CronNodeDataDto extends AbstractDto
{
     #[ApiProperty(description: '节点ID')]
     protected int $id = 0;

     #[ApiProperty(description: '是否配置了密钥')]

     protected int $status = 0;

     #[ApiProperty(description: '最后测试错误信息')]

}

要求如下：
1、单个对象响应，如果能够复用列表的CronAgentNodeRowDto就复用，不能够复用的就新增一个Dto。

2、看抽象一个BaseListResponse出来，和 Swoolefy\Http\BasePageResultResponse那样。所以List类继承于BaseListResponse。这样更好点。

3、请按照这个规范全面修复Response类，这样才能符合生成SDK固定响应结体的API。
